# 第二阶段：三域探索

第二阶段初版为128×96；当前已扩为256×192瓦片，保留旧镇、神树庭院和可进入的教堂。区域、等级带、地标及奖励在 `src/game/world-data.ts`；布局与连通性在 `world-layout.ts`；发现、迷雾、营地、守卫和传送规则在 `systems/exploration.ts`。区域难度固定，不随玩家等级抬升。

## 玩法与操作

- **M / 点击小地图 / M 圆键**：打开世界地图并暂停；再按 M / Esc 或点击关闭返回。地图上选择已发现地点追踪，界面显示方向和距离。
- **走近后 C / 点击互动键**：与界石、营地、遗箱、圣龛或眺望点互动。附近有 NPC 时保留 NPC 对话入口，教堂内外规则不变。
- 普通走动揭开半径约 260 世界像素的地图迷雾，地形墙阻挡视线；走近地标且视线可达才记录发现，地图不显示未发现的地点。眺望点首次互动获得经验并展开附近地图。
- 部分遗箱和圣龛第一次互动唤醒 2–4 名区域守卫，清除后再次互动领取奖励。守卫绑定稳定地点 ID，不会重复唤醒；背包放不下时不结算经验、不消耗奖励。奖励包括霜晶、星辉、虚空、魔域镰刀、火焰大剑及补给/护甲，让正式冒险能逐渐获得现有武器。
- 营地在附近无可见敌人、没有持续战斗法术时回复真实生命和法力，间隔 30 秒游戏时间；不能借炎躯翻倍状态额外治疗。
- C 激活界石。站在已激活界石旁，选择另一处已激活界石传送；敌人接近、投射物/持续法术未结束、两秒传送间隔未结束或落点被阻挡时拒绝。落点以玩家半径检查真实碰撞，不能从任意位置打开地图传送。

## 布局与表现

旧区域主要地形保留，新区用种子生成浅潭、林地和遗迹，主路留通。地标以固定内容锚点加种子偏移选择位置，使用从出生点搜索得到的可达空地；普通树和杂物避开地点与道路。地标有脚底碰撞，新遗迹拱门不封住视觉上的门洞。测试覆盖多个种子的全部地标接近路线。

新地标、腐树、残拱及区域地面使用程序像素帧，加入现有唯一图集。地标完成/激活状态只在渲染层切帧，不写模拟；树冠仍按脚底遮挡淡出。普通怪物继续复用原三种行为，区域倍率影响新区守卫与补怪；更多敌人机制和首领留到第四阶段。补怪同时检查附近数量和全图上限，避免远处旧怪阻止新区出现敌人。

## 存档与兼容

存档格式升到 v2，浏览器槽位键沿用 `ashen-vale.save.v1.*`，防止同域的旧槽位丢失。v1 JSON 和本地档先按旧格式验证，再恢复原 World、RNG、组件和碰撞，将 Level 扩到新尺寸并添加探索内容。旧实体不重建，原背包、光标、穿戴、任务、掉落和持续技能保留；导出的新档为 v2。

v2 保存迷雾网格、已发现地点、界石、已开始的守卫战、一次性遗箱/眺望奖励、净化状态、追踪目标、休息与传送计时。`Prop.landmark` 和 `Mob.site` 将实体与稳定内容 ID 关联。首次内容初始化完成后记录 worldVersion，后续读档不重生成守卫或奖励。旧记录仍可作为备份回退，详见 [SAVES.md](SAVES.md)。
