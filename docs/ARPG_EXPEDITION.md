# 六域远征：地图设计、地下城与横屏手感

2026-11-13，按用户确认的方案继续实现。主世界512×384（196,608格，世界像素16,384×12,288），是上一版256×192的四倍面积；新增三座独立80×80地下城。延续清晰卡通像素材质，教堂、祭坛、神树及基座使用原有素材与坐标。

## 真实地图结构

旧三区与30处旧地点保留，新增黑水湿地10–16级、断崖高地14–20级、魔裂荒原18–25级。地表共有63处地点：原30、新区30、地下城入口3；界石共12处。每座地下城另有出口、侧室遗箱和核心守卫三个地点，全部内容ID在 `world-data.ts` 定义。

`expedition-design.ts` 显式定义30个新区盆地节点、跨区通路与多个回环。`frontier-layout.ts` 从湿地水面或高地/荒原岩体中雕出不规则盆地，再连接有转折的通道；主路宽约3–4格，周边留战斗空间，湿地以栈道穿越，山地有石阶。六处旧区入口连接新区，树木和摆件避开主要通路与地点落脚位置。路外侧放地域摆件，普通树不会随机落进荒原。

所有地表地点通过出生点可达性检查；小地图现在显示附近约1280世界像素的局部视野，避免整片大陆被压缩成小点。大地图可点区域放大，并提供“全图”恢复；迷雾、地点标记及点击追踪采用同一投影。探索百分比只计算含可通行地面的迷雾格，实心山体不阻止达到100%。

## 独立地下城与状态

矿洞、腐根、旧城地牢都为80×80，八个房间预设与多条通路构成主路、侧室和回环；转角与房间轮廓随角色种子变化。进门需脱战并等待持续法术结束，核心清除后开启回程捷径，目标切换到出口；奖励仅结算一次。三种地板、环境摆件与火把区分主题。地下城不会出现地表教堂、神树或圣域地面。

`realm-travel.ts` 将离开的地图保存为休眠层，其快照完全移除玩家实体和组件；进入目标层时移入当前唯一玩家。角色ID、背包、装备身份、经验、血量、冷却均延续。每层保留敌人/掉落/破坏/随机状态；休眠层不继续模拟。进度的zone决定当前层，迷雾按zone隔离，返回原入口并恢复此前地表追踪目标。

## 摇杆与镜头

横屏摇杆112px，默认圆心约屏宽14%且有安全区留白；半浮动在左下操作区落指，不在按下时跳方向。8%中心防抖，推到约75%可达满速，斜向限幅，输入不额外延迟，旋钮仅35ms显示缓动。独占移动触点，右手技能不会抢走摇杆；松手/取消/失焦/旋转/暂停/背包/地图立即释放。

菜单记忆“固定/半浮动”和“近/标准/远”。触屏横屏默认1.30，竖屏1.45；横屏远档1.15、近档1.50。HUD保持屏幕尺寸，全屏横屏按钮继续可用。

## 性能与存档v4

- 墙体现在只创建镜头附近、接触可行走空间的边缘Sprite，实心岩体仅烘焙地表，离屏销毁；避免数万山体格生成数万显示对象。
- 继续使用单一共享地形图集、512地面分块和回收、屏外实体裁剪、局部AI/寻路。普通远怪离场，地点守卫永久保留，全图普通怪预算96，局部上限10；补怪半径按相机可见距离计算。
- 路线查询按32格空间桶筛选线段；小地图只画局部已探索迷雾格，大地图只遍历已探索格。地表外观变化有独立terrainRevision，开捷径会更新地面，普通碰撞物破坏不触发整批地面重烘焙。
- v4仍使用原本地槽位键，兼容v1/v2/v3。先恢复旧实体/装备/奖励，再添加新区，旧角色不重开。休眠层禁止包含角色副本，导入逐层验证。
- 存储/导出边界使用rle1压缩瓦片；解析与运行快照保持完整数组，校验码针对完整数据。解压先限制尺寸/长度/值与层数，避免超量分配。当前版与备份仍为一次原子写入，配额失败不覆盖旧档。

## 验证与画面

109项模拟回归，含六区多种子可达、地下城房间可达、三图往返/重载/不重领奖励、唯一角色与装备、v3迁移、RLE与存储配额、防抖/斜向推力、可达地面探索百分比；类型检查、构建及单文件导出。浏览器另检查实际双指移动+技能、松手和暂停、横竖屏/视野档位、地图分区缩放、三座地下城与读档、保护素材与离线运行。最终浏览器巡游的地面纹理峰值16MiB、单纹理源，视野内墙体峰值69；完成三座地下城且全图揭雾的压缩导出约649KB。22张教堂/祭坛/神树/地面/原墙体保护帧与上一生产版像素摘要完全相同。自动化使用软件图形渲染，未把资源预算等同于真机60帧保证。
