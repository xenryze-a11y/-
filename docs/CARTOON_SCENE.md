# 卡通场景与手机横屏

2026-11-12：按用户最新要求，普通场景改为清晰的卡通像素画风，相机稍微拉远，增加手机横屏按键。

## 外观与保留范围

`game/cartoon-scene-art.ts` 在已有美术合成后，显式覆盖普通草地、道路、水面、石板、台地/阶梯、普通树木/腐树/枯树、蘑菇、界石/营地/遗箱/眺望台、石柱/残拱、岩石/木箱/墓碑。采用大色块、三档明暗、少量点缀和硬轮廓；不使用平滑滤镜处理像素。室外圣域石板也改为清楚的板缝，古树根床和祭坛马赛克保留。

教堂屋顶/内部、教堂长椅/柱子/烛台/圣坛、古树/祭坛/根床/花坛/马赛克、探索圣龛与废弃小教堂均保留原图。浏览器对合成前后帧像素SHA256对照：14张保护帧完全一致，仅4张圣域室外地板更新。城镇墙面使用独立 `tileCartoonWallRaised0..3`；教堂边界继续引用原 `tileWallRaised0..3`，浏览器检查64块教堂墙与1012块其他墙全部引用正确。原始生成图片及处理脚本留在源码中，便于之后更换美术。

新美术仍在启动时画入同一图集，路沿/岸线只烘焙进已有512地面块；没有逐帧重画材质、额外滤镜或独立纹理源。沿用上一轮裁剪、休眠和画质档位。地面预算在本轮常规桌面/手机巡游测试仍为16MiB、一个纹理源。自动化环境帧间隔仍明显偏高，不把材质简化当作真机流畅度保证。

## 镜头与横屏按钮

桌面和手机横屏缩放2→1.65，手机竖屏1.75→1.45：对象缩小约17%，同尺寸屏幕可见面积约增加45%。按钮保持屏幕尺寸，启动、窗口变化和每帧跟随均使用 `CFG.camera` 的相同设置。

触控模式在小地图下方增加44px圆形“横屏”键，开始/暂停菜单也有“手机横屏”。直接从用户点击请求页面全屏，再尝试 `screen.orientation.lock('landscape')`；退出全屏同步解锁、更新按钮，不改存档或暂停状态。支持标准与WebKit全屏；方向锁或全屏不支持/被拒绝时明确提示手动横放，沿用真实窗口尺寸和触控坐标，不用CSS假旋转冒充设备旋转。浏览器仍可能要求用户关闭系统方向锁；不宣称所有iPhone浏览器均支持自动横屏。

## 验证

类型检查、102项回归、普通构建与单文件导出。浏览器检查新缩放、手机390×844/844×390、画质档、悬崖/阶梯、界石、存档导入/重载、技能压力与地面缓存。离线单文件零外部请求。横屏按键补充真实全屏进入/退出、支持方向锁的接口路径、浏览器拒绝和不支持时提示、横屏重排与按钮可用性。
