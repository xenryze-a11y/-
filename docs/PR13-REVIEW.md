# PR #13 审查与集成试玩

审查对象：`76am` 的 PR #13，提交 `4b48a5059540cfe05686a226a708a430e391b120`。
集成基线：六域试玩 `67136bb`（PR #12），保留 512×384 地表、三个 80×80 地下城与手机操作。

## 审查发现（原 PR，均已在本分支修复）

1. **P1：死亡掉落会复制物资。** `death-stash.ts::recordDeathStash` 只复制堆叠，不从背包扣除；`main.ts::installScene` 在读取死亡前的健康存档后再生成一份。存档内原物资仍在，死亡、继续、拾取即可增加资源。全局遗物键只匹配 seed，也未区分槽位与地下城，且消费后尚未保存就刷新会丢失现场。
   修复：模拟层生成隔离的完整复苏场景，先扣物资再生成同层遗物，由组装层通过 SaveRepository 一次原子写入；读取不另生物资。失败保留上一有效存档，旧全局遗物键不再参与游戏。
2. **P2：疲劳和感染使普攻反而更快。** `magic.ts` / `blades.ts` 把冷却乘上 0.78/0.9；冷却缩短，实际攻击频率上升。
   修复：冷却除以攻速倍率；验证剑类与法杖共用的实际输入路径。疲劳和负重的翻滚距离也改为叠乘，拒绝翻滚仍可步行。
3. **P2：疲劳没有恢复途径。** 每 1500 秒（重载更快）永久降为零，食品、药水和营地都不回精力，存档保留后角色始终无法翻滚。
   修复：安全营地休息回满精力，沿用原休息冷却和脱战要求。

4. **P2：新增生存条遮住任务。** 原有任务框使用固定 top，五条状态把生命面板撑高后两者重叠。修复为内容自适应纵向排列，横屏短高度改为并排和双列细条，保留原战斗圆键。

## 集成兼容处理

双方都使用了 v4，但含义不同：PR #12 的 v4 是六域地图，PR #13 的 v4 是旧地图生存版，v5 加暑热。新格式升为 **v6**，结合 worldVersion/zone 区分两条 v4，仍先核对校验码再恢复，验证过程不修改输入。

- v1/v2/v3 与六域 v4：补满生存初值；六域休眠层补空 survival 表，跨图移入唯一角色。
- 共创 v4/v5：扩展到六域，保留已有饱食、疲劳、装备、时间和 RNG；v4 仅补零暑热。
- 地下城遗物跟随该层保存，不会在地表同坐标生成。
- 生存模拟与背包不访问浏览器存储；出图软件 Canvas 仅用于开发/测试，不进入游戏包。

## 试玩提示

冒险模式初始带干粮、清水和绷带。在背包将其放入物品栏，选中后按 X /「使用」。月露草可解感染；营地休息恢复生命、法力、精力。季节与昼夜由世界时间推进，衣物影响舒适温度。

倒下后「继续冒险」会在当前地图出生点复苏，部分堆叠物资留在倒下处。此过程写入当前存档，失败则回到之前有效进度。独立的全武器试用不写冒险存档。
