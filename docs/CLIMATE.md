# 气候与衣物

第 1 批：季节气温 + 衣物保暖 / 耐热。规则在 `src/game/climate.ts`（算温度）与
`src/game/systems/survival.ts`（把温度换算成状态），数值在 `data.ts` 的 `SURVIVAL` /
`climate.ts` 的 `SEASONS` / `CLIMATE`，衣物属性在 `armor.ts`。决策见 [DECISIONS.md](DECISIONS.md) D47。

## 核心公式

```
抗寒 = 各部位 insulation 之和（含鞋）
耐热 = 各部位 cooling 之和（含鞋）
舒适区间 = [ 5 − 抗寒 × 1.2 , 25 + 耐热 × 2 ]   （摄氏）

环境气温 < 区间下限  → 抗寒下降，速率 = 低于度数 × 0.055 / 秒
环境气温 > 区间上限  → 暑热上升，速率 = 超出度数 × 0.055 / 秒
落在区间内          → 抗寒与暑热以 1.2 / 秒回到安全值
```

环境气温 = 季节基础 + 昼夜偏移 + 水域 / 火堆微环境。

**抗寒（warmth）与暑热（heat）是两条独立状态**，各自归零后持续掉血（2.6 与 2.4 每秒）。
这样冷和热可以分别处理，也不与现有 HUD / 存档结构冲突。

## 季节

| 季节 | 基础气温 | 时长 |
|---|---|---|
| 春 | +12°C | 480 秒 |
| 夏 | +28°C | 600 秒 |
| 秋 | +12°C | 480 秒 |
| 冬 | −8°C | 720 秒 |

一年 2280 秒（约 38 分钟）。**季节由 `world.time` 推导，不存字段**——时间已经进存档，
跨局天然保留，迁移也不会丢季节。

昼夜：一昼夜 120 秒，夜晚从 0.55 开始，白天 +4°C、夜晚 −10°C。

微环境：水域附近 −10°C，营火 / 火把旁 +40°C。

## 衣物属性

| 材质 | 减伤 | 保暖 | 耐热 | 定位 |
|---|---|---|---|---|
| 无 | 0 | 0 | 0 | 赤身 |
| 皮革 | 0 | 4 | 0.5 | 保暖主力，夏天偏热 |
| 铁甲 | 头/腿 1、胸 2 | 0.5 | 1 | 减伤最高，但**不保暖** |
| 晨曦 | 头/腿 1、胸 2 | 2.5 | 2 | 均衡，套装每秒 +2 法力 |
| 毛皮 | 0 | 7 | 0 | 御寒最好，夏天闷热 |

鞋也参与：布鞋 0.5 / 皮靴 1 / 铁靴 0.5 / 圣靴 1.5（保暖），耐热铁靴 1、圣靴 1.5。

**毛皮斗篷**（`fur_chest`）走胸甲位，怪物掉落概率约 2%，是冬夜外出的关键装备。

## 冬季体感（供调参参考）

冬夜环境 −18°C：

| 穿着 | 舒适下限 | 低于度数 | 抗寒下降 |
|---|---|---|---|
| 赤身 | +5 | 23 | 1.27 / 秒 |
| 皮甲三件 + 皮靴 | −9.4 | 8.6 | 0.47 / 秒 |
| 毛皮三件 + 皮靴 | −13 | 5 | 0.28 / 秒 |
| 铁甲三件 + 铁靴 | +3.2 | 21.2 | 1.17 / 秒 |

夏日白天 +32°C：赤身舒适上限 25 → 超出 7 度，暑热 0.39 / 秒（约 4 分钟涨满）；
晨曦全套上限 29 → 超出 3 度，明显更凉快。
